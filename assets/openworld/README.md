# Original world textures and source inventories
Ten original textures accompany the DeepSeek polygon builders.
The three original families are in uzdoom/openworld/environments.py; four
additional families are in archetypes.py and two final families in
archetypes_extra.py. Source manifests retain the worker inventories, including
CPU previews outside this repository. They are provenance, not local file lists.
SHA256SUMS covers this bank. Reviewed geometry variants are17/73/211; the run
selector shuffles seven distinct families from nine and records its full plan.
See uzdoom/README.md for the native collision/visibility adapter and limitations.
