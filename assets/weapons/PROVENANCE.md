# Provenance and licence

All images in this pack were produced procedurally by `generate_weapons.py` on this machine on 2026-11-01, using only Python, Pillow and NumPy. No photographs, scans, Freedoom or Doom/IWAD sprite pixels, external textures or third-party models were used. The game frames contain no text or embedded fonts; only the review contact sheets use Pillow's bundled default label font. Names, silhouettes, material language and the glove/sleeve design are original to this pack.

The Quake-era chunky polygon/painted-texture look is a broad stylistic target, not a copy of any specific weapon, logo, pose or asset. No weapon in the pack is intended to read as a real firearm or a recognisable franchise design.

Generated for Josiah's Null Run project and included under the surrounding repository's existing licence. The worker's provisional CC0 suggestion was not an approved project licensing decision; the untouched source report remains in the original worker folder.
