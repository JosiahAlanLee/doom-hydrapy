# Native actor source bank
Original meshes and atlases generated by DeepSeek for Josiah's Null Run.
Fourteen humanoid bosses are from nullrun-humanoid-bosses-20261031; four mobs
were refined in nullrun-art-round2-20261031. Source manifests describe untouched
upstream inventories. SHA256SUMS describes these reviewed copies.
The packer uzdoom/models.py validates UV/topology compatibility and writes MD3
morph frames; generated MD3 files are build outputs. Bosses have six source
poses, with neutral reused for the second movement slot; mobs have seven.
Collision and combat stay in NRMonster; only presentation is overridden.
