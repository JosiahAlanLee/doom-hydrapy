# NULL RUN / THRESHOLD — people, sources and licenses

Creative direction, world/bestiary collaboration and the project: Josiah Alan-Lee.

## Engine and foundation

- Doom engine: id Software and its original contributors; preserved copyright and GPL notices in the engine sources. https://github.com/id-Software/DOOM
- Doomgeneric: its maintainers and contributors; preserved upstream sources and notices in this repository. https://github.com/ozkl/doomgeneric
- Chocolate Doom: Simon Howard and contributors; its contributions and copyright notices are preserved in the ported engine sources. https://www.chocolate-doom.org/
- Freedoom: The Freedoom Project and its credited artists, sound designers and maintainers. The operator supplies the Freedoom IWAD; retained foundation sprites/weapons and texture resources are credited to that project. Its license is retained with the installed IWAD and copied into this build's asset notices. https://freedoom.github.io/

## New work and collaboration

- Argon: the original Null Run monster concepts and procedural sketches, including Surveyor, Wire Shambler/Ballast Husk, Threshold Mimic and Vore Spindle. Original inputs, derivative render sources and GPL notices are in assets/argon/.
- Argon gameplay-optics proposal: adapted into the optional native Surveyor countdown operator by Codex. The unchanged GPL source, hash, implementation boundaries and verification are recorded in SURVEYOR_OPTICS.md and assets/argon/provenance/Gameplay-Optics-original.py.
- DeepSeek-assisted procedural content: the Threshold opening floor, environment kit, Latchwing and Relay Choir art, and the paired original tracker composition. The preserved generator, per-file manifest and review record identify the actual delivered content and any later Codex repairs.
- Codex: native enemy adaptation, controls, map/art integration, interface, validation, performance checks and rendering coordination.
- Claude: earlier engine, creative-tooling and render-machine collaboration. Task handoffs and the Git history retain individual changes.
- HydraPy, Gorgon and DSP_Emulation: Josiah Alan-Lee and their contributing collaborators. These supply the GPU scene, tracker/audio integration and PVX/Spoon Bender instruments. Their own licenses and source notices apply to those projects and plugins.

## License record

The game code and the new derivative content kit use GPL-2.0-or-later except where an included file identifies another applicable license. The font has its separate SIL OFL license. Existing upstream and Freedoom asset notices remain applicable to their files. Credit identifies actual sources and model-assisted contributions; code, art, written score and rendered music are tracked separately in the build's provenance report.

## Seeded environment worlds and signature mobs

Drowned Records, Switchyard Chapel and After Hours Pavilion: original procedural art and written scores generated by DeepSeek under Josiah Alan-Lee's direction; GPL-2.0-or-later. Codex supplied seeded selection, native asset/frame adapters, current mob warning labels and independent review. Six new visual identities reuse two existing behavior families. Matching scores are written data, without live playback in this change. Preserved generators, manifests, checks and artifact credits: assets/environments/CREDITS.md and EXPANSION.md.
