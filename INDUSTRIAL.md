# Original industrial take

The industrial path accepts four original six-lane `hydrapy-tracker-3` scores. `industrial_music.py OUTPUT SCORE1 SCORE2 SCORE3 SCORE4` validates and evaluates the authoritative tracker format, then compiles its fired events to the polyphonic Rack stream. Each score must last exactly 60 seconds. Unsupported note locks fail explicitly. Instruments follow lane identity: PVX bass, PVX lead, CZish rhythm, Vastish layer, OTIS drums, OTIS percussion. Drum pitches select the existing eight original sample families; each family gets its own polyphonic route. More than eight overlapping synth notes allocate another instance instead of stealing voices.

Use the same frozen HydraPy runtime and private JACK/Rack setup as the first take. Set `DOOM_TAKE_ROOT` to a new writable run directory, `DOOM_INDUSTRIAL=1`, `PVX_PLUGIN_DIR` to the reviewed build, and `DOOM_DELIVERY_DIR` to the delivery folder. The run directory needs `poly/{schedule,notes,mapping}.json`, `poly/{INSTRUMENTS.md,inventory.json}`, `provenance.json` and `pvx-routing.json`. The latter declares plugin/model slugs, pitch/gate/audio/velocity port IDs, and parameter dictionaries by lane number. No plugin installation in the user's Rack folders is needed.

Prepare with `setup_take.py --smoke`, then `run_capture.sh smoke`. Only after checking that capture, prepare with `setup_take.py` and run `run_capture.sh poly`. Every scene and demo changes on the same minute boundary, 0/60/120/180 seconds; each demo runs for one minute. `DOOM_DATA_ROOT` selects the existing read-only Freedoom WADs. No capture may overlap another capture or Blender render.

`finalize_take.py` measures this capture's gate edges, XRUNs, frame holds, tic sync and optical/audio markers, fully decodes the final media and extracts eight review frames per minute. Manual final-video inspection, a report and delivery SHA256SUMS are still required. The legacy `finish_delivery.py` is specific to the first take and MUST NOT sign off an industrial take. Never reuse its hard-coded results or credits.
